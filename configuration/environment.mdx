Lyra reads its runtime configuration from environment variables and a `.env` file that is auto-generated by `setup.sh`. The file is written to the project root with `chmod 600` permissions and is sourced automatically by the Node.js server via `dotenv`. You should not edit it by hand after setup — re-running `setup.sh` will regenerate it only if keys are missing.

## Secrets (`.env`)

`setup.sh` generates two cryptographic secrets on first run and appends any missing ones on subsequent runs. Both values are also written to `services/cloudsync/.env` alongside `COOKIE_SECURE=true`.

<ParamField body="JWT_SECRET" type="string" required>
  Minimum 64 hex characters (256 bits). Used by CloudSync to sign and verify JWT session tokens. Must differ from `SYNC_SECRET`.
</ParamField>

<ParamField body="SYNC_SECRET" type="string" required>
  Minimum 32 hex characters (128 bits). Used to derive the AES-256-GCM encryption key for sync data at rest. Must differ from `JWT_SECRET`.
</ParamField>

<Warning>
  `JWT_SECRET` and `SYNC_SECRET` must be different values. Using the same value for both would allow a sync-data key to be reused as a session signing key, which is a security vulnerability.
</Warning>

## Node.js Server (`server/prod.mjs`)

These variables are read by the main Lyra application server process, managed by PM2 as the `lyra` app.

<ParamField body="NODE_ENV" type="string" default="production">
  Runtime environment. Set to `production` by `setup.sh`. The dev server (`server/dev.mjs`) uses `development`.
</ParamField>

<ParamField body="PORT" type="number" default="4444">
  TCP port the HTTP/2 server listens on. Caddy proxies to this port for all fallback and static-asset routes.
</ParamField>

<ParamField body="MOCHI_ORIGIN" type="string" default="http://127.0.0.1:4000">
  Origin URL of the upstream Mochi load-balancer endpoint. The Node.js server forwards game-proxy requests (`/!!/`, `/!!raw/`, `/!!folio/`, `/!cover!/`, `/stream/`) to this origin.
</ParamField>

<ParamField body="WEBRTC_TURN_ENABLED" type="string" default="1">
  Set to `1` to include TURN server configuration in the `/api/stuff` response consumed by the client. Set to `0` to return `{ enabled: false }` and disable ICE relay entirely.
</ParamField>

<ParamField body="WEBRTC_FORCE_RELAY" type="string" default="1">
  Set to `1` to advertise relay-only ICE (`forceRelay: true`) to the client. Set to `0` to allow direct and STUN candidates in addition to TURN.
</ParamField>

<ParamField body="TURN_HOST" type="string">
  Hostname or IP address of the TURN server included in ICE server configuration. Defaults to the server's detected public IP address when not set.
</ParamField>

<ParamField body="TURN_PORT" type="number" default="3478">
  Port of the TURN server. Used both in the ICE server config and in the `/eturnal/health` TCP probe.
</ParamField>

<ParamField body="TURN_USERNAME" type="string" default="lyly">
  TURN credential username passed to the WebRTC client.
</ParamField>

<ParamField body="TURN_CREDENTIAL" type="string" default="rara">
  TURN credential password passed to the WebRTC client. Set to a random 48-character hex string by `setup.sh`.
</ParamField>

## Mochi

Mochi instances are managed by systemd (`mochi@N.service`). Each instance reads its port from `/etc/mochi/instance-N.env`; remaining tuning parameters are set in the service unit's `Environment=` lines.

<ParamField body="MOCHI_PORT" type="number" default="4002">
  Bind port for this Mochi instance. `setup.sh` sets this to `4100 + N` for instance N; the dev server uses port `4002` for the single development instance.
</ParamField>

<ParamField body="MOCHI_HOST" type="string" default="0.0.0.0">
  Bind address. `setup.sh` sets this to `127.0.0.1` in the systemd unit so instances are only reachable from localhost.
</ParamField>

<ParamField body="MOCHI_INSTANCES" type="number" default="auto">
  Total number of Mochi instances running concurrently. Consumed by `tuning.rs` to divide the system memory and CPU budget per instance. `setup.sh` auto-detects this from CPU count and available RAM (capped at 32).
</ParamField>

<ParamField body="MOCHI_STREAM_CACHE_GB" type="number">
  Disk cache size in GB per instance for HLS stream segments. Capped at 75 % of available disk space. If unset, Mochi auto-tunes based on available disk.
</ParamField>

<ParamField body="MOCHI_STREAM_CACHE_TTL_DAYS" type="number">
  Maximum age in days for stream cache entries (clamped to 1–30). If unset, defaults to `1` (< 100 GB disk) or `2` (≥ 100 GB disk) as calculated by `tuning.rs`.
</ParamField>

## CloudSync

CloudSync is launched by PM2 from `services/cloudsync/target/release/cloudsync`. Its `.env` file (at `services/cloudsync/.env`) is written by `setup.sh` and contains `JWT_SECRET`, `SYNC_SECRET`, and `COOKIE_SECURE`.

<ParamField body="JWT_SECRET" type="string" required>
  Same value as the root `.env` secret. CloudSync uses this to issue and verify session JWTs.
</ParamField>

<ParamField body="SYNC_SECRET" type="string" required>
  Same value as the root `.env` secret. CloudSync uses this to derive the AES-256-GCM key for user sync payloads.
</ParamField>

<ParamField body="COOKIE_SECURE" type="string" default="true">
  When `true`, session cookies are sent with the `Secure` flag. Always set to `true` by `setup.sh` for production.
</ParamField>

<ParamField body="CLOUDSYNC_PORT" type="number" default="4005">
  Port CloudSync binds on. Caddy routes `/api/auth/*` and `/api/sync/*` to this port.
</ParamField>

<ParamField body="CLOUDSYNC_DB_PATH" type="string" default="services/cloudsync/.db">
  Path to the SQLite database file. The WAL files (`.db-shm`, `.db-wal`) are expected alongside it. `setup.sh` sets this to the absolute path inside the repo.
</ParamField>

<ParamField body="CLOUDSYNC_MEMORY_MB" type="number">
  Memory budget in MB passed to `tuning.rs` to cap SQLite cache size, mmap size, and worker concurrency. Set by `setup.sh` to approximately 6 % of total RAM (128–768 MB). If unset or set below 128, the system's available memory is used directly.
</ParamField>

## Isao

<ParamField body="ISAO_PORT" type="number" default="4003">
  Port the Isao anime metadata API service binds on. Caddy routes `/api/anime/*` to this port. `setup.sh` always passes `ISAO_PORT=6001` in the PM2 environment, overriding the binary default.
</ParamField>

## Setup-Time Overrides

These variables are read by `setup.sh` before any services are started or configured. Set them in your shell before running `bash setup.sh`.

<ParamField body="MOCHI_INSTANCES" type="number">
  Override the auto-detected Mochi instance count (1–32). Auto-detection uses `min(cpus / 2, ram_mb / 2048)` and may further reduce the count if available disk space is insufficient for one cache GB per instance.
</ParamField>

<ParamField body="NURU_INSTANCES" type="number">
  Override the auto-detected Nuru instance count (1–18). Auto-detection uses the same CPU/RAM formula as Mochi with an additional cap of 18.
</ParamField>

<ParamField body="TURN_HOST" type="string">
  Override the TURN server hostname baked into the eturnal config and PM2 environment. Defaults to the server's detected public IPv4 address.
</ParamField>

<ParamField body="TURN_PORT" type="number" default="3478">
  Override the TURN server port in eturnal config and PM2 environment.
</ParamField>

<ParamField body="TURN_USERNAME" type="string" default="lyly">
  Override the TURN credential username written to `/etc/eturnal.yml`.
</ParamField>

<ParamField body="TURN_CREDENTIAL" type="string">
  Override the TURN credential password written to `/etc/eturnal.yml`. If unset, `setup.sh` generates a random 48-character hex value.
</ParamField>

<ParamField body="LYRA_WIREGUARD" type="string">
  Set to `yes` (or `1` / `true` / `y`) to enable WireGuard routing non-interactively. Requires a pre-existing `/etc/wireguard/wg0.conf`. See the [WireGuard guide](/configuration/wireguard) for details.
</ParamField>
