Lyra is a self-hosted web proxy that runs entirely in the browser. It bundles a fast Rust-powered proxy backend, free anime streaming with HLS caching, thousands of aggregated games, encrypted cloud sync, and tab-cloaking — all deployable from a single `bash setup.sh` command on any Debian/Ubuntu server.

## What's Inside

Lyra is composed of several purpose-built services that work together:

<CardGroup cols={3}>
  <Card title="Mochi" icon="shield" href="/architecture/mochi">
    Rust reverse proxy with RAM + disk caching and HTML/JS rewriting
  </Card>
  <Card title="Nuru" icon="network-wired" href="/architecture/nuru">
    Rust Wisp v2 WebSocket server for TCP/UDP tunneling
  </Card>
  <Card title="Folio" icon="browser" href="/architecture/folio">
    Service-worker proxy engine with JavaScript AST rewriting
  </Card>
  <Card title="Anime" icon="film" href="/features/anime">
    Free streaming with HLS and per-instance disk cache
  </Card>
  <Card title="Games" icon="gamepad" href="/features/games">
    Thousands of browser games from multiple curated sources
  </Card>
  <Card title="Cloud Sync" icon="cloud" href="/features/cloud-sync">
    Encrypted bookmark and settings sync backed by SQLite
  </Card>
</CardGroup>

## Quick Start

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/awsdredtfyug/lyra.net
    cd lyra.net
    ```
  </Step>
  <Step title="Run the setup script">
    The setup script installs all dependencies, compiles Rust services, and configures systemd + Caddy automatically.
    ```bash
    bash setup.sh
    ```
  </Step>
  <Step title="Access your instance">
    Once setup completes, Lyra is live on port 443 with automatic on-demand TLS. Point a domain at your server's IP and browse to it.
  </Step>
</Steps>

<Note>
  The setup script requires a Debian or Ubuntu system with `systemd`, `apt`, and cgroup v2 enabled. See [Self-Hosting](/self-hosting) for full prerequisites and optional WireGuard VPN routing.
</Note>
